## Overview

This repository is an organized, comprehensive, and student-focused preparation suite for the **Huawei HCIA-AI V4.0 Certification Exam (H13-311_V4.0)**. 

Curated by **Umed Jamal Nouri** (Senior B.Sc. Electrical Engineering student at Salahaddin University – Erbil), this suite synthesizes official courseware, hands-on lab experiments, and extensive question banks into a clean, intuitive structure designed to help candidates prepare methodically and pass the certification with confidence.

${\color{#10B981}\textsf{\textbf{TIP}}}$ &nbsp;**Official Exam Specification (`H13-311_V4.0`):** 60 examination items (Single Choice, Multiple Choice, True/False) · 90-minute limit · Passing threshold: **600 / 1000 points** (60%).

### Interactive Deep Learning Web App: GullNas Vision

A high-performance, modern Claymorphism web application powered by **PyTorch ResNet-50** for real-time botanical flower classification across 5 categories (*Daisy, Dandelion, Roses, Sunflowers, Tulips*):

${\color{#8B5CF6}\textsf{\textbf{IMPORTANT}}}$ &nbsp;**Production Vision Benchmark:** Fine-tuned `torchvision.models.resnet50` on NVIDIA RTX 5060 Laptop GPU achieves **90.20% overall accuracy** with **~5–8 ms inference latency**.

- **Model Architecture:** Official `torchvision.models.resnet50` (25.5 Million parameters, bottleneck residual blocks).
- **Benchmark Accuracy:** **90.20% overall test accuracy** on the HCIA-AI evaluation set (100.0% on Roses & Sunflowers, 99.9% on Dandelion, 99.6% on Daisy).
- **Inference Speed:** Accelerated via CUDA on `NVIDIA GeForce RTX 5060 Laptop GPU` (~5–8 ms ultra-low latency inference).
- **Botanical Taxonomy:** Clean, scientific interface displaying botanical nomenclature (*Bellis perennis*, *Taraxacum officinale*, *Rosa*, *Helianthus annuus*, *Tulipa*) and full probability distributions.
- **Interactive UI:** Drag-and-drop image upload, clipboard paste (`Ctrl+V`), and curated preset gallery embedded with real dataset photographs from `flower_photos_test`.

**Quick Launch:**
- **Windows (One-Click):** Double-click [`start_ui.bat`](./03_HCIA-AI_Labs/Dataset/MNIST/start_ui.bat) — automatically starts the model server and launches the interactive UI in your web browser (`http://127.0.0.1:5000`).
- **Terminal Execution:**
  ```bash
  cd 03_HCIA-AI_Labs/Dataset/MNIST
  python app.py
  ```
  *(The browser opens automatically at [http://127.0.0.1:5000](http://127.0.0.1:5000) upon launch)*

## Recommended Study Roadmap

${\color{#10B981}\textsf{\textbf{TIP}}}$ &nbsp;**Structured Preparation Sequence:** Progress methodically from fundamental AI theory through code syntax to timed mock exams.

1. **Phase 1: Foundation Review**  
   Read through the [Training Material](./04_Course_Materials/HCIA-AI%20V4.0%20Training%20Material.pdf) and review the [Comprehensive Study Guide](./04_Course_Materials/HCIA-AI_V4.0_Comprehensive_Exam_Focus_Study_Guide.pdf).

2. **Phase 2: Chapter-by-Chapter Practice**  
   Print the [Student Answer Sheets](./01_Code_Mastery_Guide/HCIA-AI_V4.0_Student_Answer_Sheets_Printable.pdf) and solve Chapters 1 through 6 in [`02_Question_Banks/Individual_Modules_100Q/`](./02_Question_Banks/Individual_Modules_100Q/). Check your answers using the page footers.

3. **Phase 3: Coding Syntax Practice**  
   Work through the [Code Writing Mastery Guide](./01_Code_Mastery_Guide/HCIA-AI_V4.0_Code_Writing_Fill_in_the_Blank_Mastery_Guide.pdf) to master PyTorch, MindSpore, and Scikit-Learn APIs.

4. **Phase 4: Simulated Timed Exams**  
   Take **Practice Exam Set 1**, **Practice Exam Set 2**, and the **Comprehensive Final Mock Exam** under timed conditions (90 minutes, target score ≥ 600/1000).

5. **Phase 5: Final Rapid Review**  
   Review the [Master Solved Direct Answers Edition](./02_Question_Banks/HCIA-AI_V4.0_Master_Question_Bank_Solved_Direct_Answers_900Q.pdf) and the [High Yield Exam Focus Summary](./04_Course_Materials/HCIA-AI_V4.0_High_Yield_Exam_Focus_Summary.pdf) 24 hours prior to the official exam session.
